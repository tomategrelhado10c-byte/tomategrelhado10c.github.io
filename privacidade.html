Política de Privacidade - SMIP

1. Finalidade

O SMIP é um projeto acadêmico que utiliza visão computacional para identificar irregularidades em pavimentos.

2. Dados acessados

O sistema utiliza autorização OAuth 2.0 para acessar o Google Drive da conta autorizada pelo proprietário.

3. Utilização dos dados

O acesso ao Google Drive é utilizado para enviar e armazenar imagens produzidas pelo sistema de monitoramento.

4. Armazenamento

As imagens são armazenadas na conta Google Drive autorizada. O armazenamento e a conservação dos arquivos dependem das configurações dessa conta.

5. Compartilhamento

O acesso aos arquivos depende das permissões configuradas pelo proprietário da conta Google Drive.

6. Segurança

A autenticação utiliza OAuth 2.0 e o software rclone para estabelecer a comunicação com o Google Drive.
