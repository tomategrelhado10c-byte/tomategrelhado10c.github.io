SMIP - Sistema de Monitoramento de Irregularidades no Pavimento

Sobre o projeto

O SMIP é um projeto acadêmico de desenvolvimento tecnológico destinado à identificação automatizada de irregularidades em pavimentos por meio de visão computacional e inteligência artificial.

O sistema utiliza um Raspberry Pi 4 equipado com uma câmera para capturar imagens de vias públicas e identificar possíveis buracos no pavimento.

As imagens capturadas são encaminhadas ao Google Drive autorizado pelo proprietário do sistema, utilizando o software rclone e a API do Google Drive.
